 User Registration Sequence
 
 @startuml Registration_Sequence
actor User as U
participant "Web UI" as UI
participant "API Gateway" as API
participant "Authentication" as Auth
participant "Database" as DB
participant "Notification" as Notif
participant "SMS/Email" as SME

U -> UI: Enter Registration Details
UI -> API: POST /register
API -> Auth: processRegistration()
Auth -> DB: checkEmailExists()
DB --> Auth: returns false
Auth -> DB: checkMobileExists()
DB --> Auth: returns false
Auth -> Auth: hashPassword()
Auth -> DB: createUser()
DB --> Auth: UserCreated
Auth -> Notif: sendOTP()
Notif -> SME: sendSMS/Email
SME --> Notif: Sent
Notif --> Auth: OTP Sent
Auth --> API: RegistrationSuccess
API --> UI: 201 Created
UI --> U: Display OTP Verification
